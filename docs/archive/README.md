## Why Archive?

These documents are archived rather than deleted to:

1. **Preserve Context** - Maintain historical record of decisions and implementation
2. **Reference Lessons** - Document what worked and what didn't
3. **Track Evolution** - Show how the project evolved over time
4. **Aid Onboarding** - Help new contributors understand project history

## Using Archived Docs

**When to reference archived docs**:

- Understanding historical context
- Learning from past implementation approaches
- Researching why certain decisions were made
- Comparing current vs previous approaches

**When NOT to use archived docs**:

- For current implementation guidance (use main docs/)
- For active development standards (use main docs/)
- For deployment procedures (use main docs/)
